# Рысик — переносимая версия сайта

Это самостоятельная копия сайта: все используемые изображения находятся в папке client/public/assets/, а код уже ссылается на локальные файлы.

## Запуск на компьютере

Установите Node.js 20+ и pnpm, затем в папке проекта выполните:

    pnpm install
    pnpm dev

## Сборка для другого хостинга

Выполните:

    pnpm install
    pnpm build

Готовая статическая часть сайта появится в папке dist/public/. Её можно загружать на хостинги со статическими сайтами.

## Важно

Фотографии уже включены в архив и не зависят от хранилища Manus.
